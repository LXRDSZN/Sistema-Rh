# 🧑‍💼 Sistema de Recursos Humanos (RH)

> Un sistema moderno, seguro y escalable para la gestión integral de empleados, asistencias, vacaciones y documentación.  
> Desarrollado con **Vue.js**, **Node.js**🚀  

---

## 🌟 Características principales

- 📋 **Gestión de empleados** — Control total de información, áreas y puestos.  
- ⏰ **Asistencias y ausencias** — Registro automatizado y reportes por periodo.  
- 🏖️ **Vacaciones** — Solicitud y aprobación desde un panel interactivo.  
- 🧾 **Documentación digital** — Carga y control de contratos o archivos laborales.  
- 🔐 **Roles y permisos** — Control de acceso para **Administrador**, **Gerente** y **Usuario**.  
- ☁️ **Infraestructura en Cloudflare** — Optimizada para rendimiento y seguridad.  

---

## ⚙️ Instalación del sistema

```bash
# 1️⃣ Clonar el repositorio
git clone git@github.com:LXRDSZN/Sistema-Rh.git

# 2️⃣ Acceder al proyecto
cd Sistema-Rh

# 3️⃣ Instalar dependencias
npm install

# 4️⃣ Iniciar el servidor de desarrollo
npm run dev
